# Dataset folder

The training script downloads UCI PhiUSIIL dataset ID 967 on the first run and caches the minimal URL/label table as `phiusiil_url_labels.csv`.

The cache is generated locally and is ignored by Git. Do not upload the downloaded data file unless your faculty specifically asks for it and the dataset license/attribution requirements are followed.

Official source: https://archive.ics.uci.edu/dataset/967/phiusil%2Bphishing%2Burl%2Bdataset
